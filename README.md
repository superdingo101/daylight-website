# Daylight

**[daylightcalendar.com](https://daylightcalendar.com)** is the home of Daylight, a collection of calendar tools for Home Assistant.

Daylight helps you bring events into your calendars and bring your schedule together in a beautiful, customizable view.

## Projects

### [Daylight Calendar Card](https://card.daylightcalendar.com)

A customizable Home Assistant calendar card that brings multiple calendars together in clear, colorful views.

[Documentation](https://card.daylightcalendar.com) · [GitHub](https://github.com/superdingo101/daylight-calendar-card)

### [Daylight Calendar Import](https://import.daylightcalendar.com)

A Home Assistant integration that turns flyers, emails, images, and PDFs into calendar events you can review and approve.

[Documentation](https://import.daylightcalendar.com) · [GitHub](https://github.com/superdingo101/daylight-calendar-import)

## About this repository

This repository contains the simple, static landing page at **daylightcalendar.com**, hosted on GitHub Pages. The website is built with HTML and CSS and has no build dependencies.

The two Daylight projects and their documentation are maintained separately.
